# Конституция проекта

Жёсткие правила. Если правило здесь противоречит привычкам или инструментам с
другого проекта, действует это правило. Изменения — только явным решением
владельца, отдельным коммитом.

## 1. Скоуп

1.1. Проект личный, вне рабочего скоупа. Он не связан с рабочими системами и не
является их частью.

1.2. Спецификации, документация и код живут в этом репозитории и версионируются
вместе. Стор `zakharov-llm` этим проектом не используется.

## 2. Внешние системы

2.1. **Confluence запрещён.** Никаких страниц, комментариев, ссылок, макросов,
интеграций и упоминаний в артефактах.

2.2. **Jira запрещена.** Никаких тикетов, переходов статусов, комментариев,
ссылок и упоминаний в артефактах.

2.3. Трекер — GitHub Issues. Issue заводится на первом этапе работы над задачей
из `ROADMAP.md`, когда идея начинает прорабатываться. Одна задача roadmap — один
issue — один OpenSpec change. Issue закрывается при архивации change.

2.4. Разрешённые сетевые обращения: загрузка весов моделей с Hugging Face,
endpoint edge-tts, git-операции с `github.com`. Всё остальное — по явному
разрешению владельца.

2.5. Внешних записей нет вообще: проект ничего и никуда не публикует.

## 3. Документация

3.1. Человекочитаемая документация — Markdown в `docs/`. Формальные
спецификации — `openspec/specs/`. Спека описывает поведение (SHALL, WHEN/THEN),
док объясняет систему людям и не противоречит спеке.

3.2. Диаграммы — Mermaid в код-фенсах. Изображения и внешние макросы не
используются.

3.3. Документация обновляется при архивации change: черновик из change
семантически вливается в `docs/capabilities/<capability>.md`, при изменении
компонентов обновляется `docs/architecture.md`. Документация не может устареть
«потому что забыли»: шаг обязателен в archive-флоу.

## 4. Данные и приватность

4.1. Секреты, токены и ключи не коммитятся. Конфигурация — только через
переменные окружения или локальные файлы из `.gitignore`.

4.2. Модели, кэш, логи и база генерируемых артефактов — вне репозитория:
`models/`, `.cache/`, `logs/`, `data/`.

4.3. Тексты сообщений и голосовые образцы не отправляются в сторонние сервисы,
кроме явно перечисленных в п. 2.4.

## 5. Лицензии

5.1. Использование некоммерческое. Веса MusicGen — CC-BY-NC 4.0.

5.2. edge-tts — неофициальный endpoint Microsoft; его нестабильность не является
основанием добавлять другие внешние сервисы без разрешения.

## 6. Схема процесса

6.1. Схема `taxmonitor` подключается симлинком из рабочего стора и не копируется
и не редактируется здесь. Все различия проекта выражены в
`openspec/config.yaml`.

6.2. Если схема потребует изменений, несовместимых с этим проектом, решение
принимается владельцем; молчаливый форк запрещён.
