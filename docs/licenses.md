# Лицензии и внешние сервисы

Проект некоммерческий (`CONSTITUTION.md` п. 5.1). Здесь — статус зависимостей,
которые накладывают ограничения или не дают гарантий.

## MusicGen (фаза 4)

Веса MusicGen распространяются под **CC-BY-NC 4.0**: использование только
некоммерческое. Модели скачиваются с Hugging Face и лежат вне репозитория
(`models/`).

## edge-tts (фаза 3)

`edge-tts` — библиотека к неофициальному endpoint Microsoft. Публичного
контракта и гарантий стабильности нет: сервис может ограничить доступ или
изменить протокол без предупреждения. По `CONSTITUTION.md` п. 5.2 нестабильность
edge-tts не является основанием подключать другие внешние сервисы без явного
разрешения владельца; альтернатива — локальный провайдер (фаза 9).

Отправляемые данные: только текст для озвучки и имя голоса. Голосовые образцы
не отправляются (`CONSTITUTION.md` п. 4.3).

## ffmpeg

Внешний бинарь, поставляется пользователем (Homebrew, apt, dnf и т. п.).
Лицензия зависит от сборки; проект использует его как отдельный процесс и не
распространяет бинарь.
