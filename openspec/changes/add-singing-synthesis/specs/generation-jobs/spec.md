# Spec Delta

## ADDED Requirements

### Requirement: Режим задачи

Задача SHALL иметь режим `song` или `narrated`; по умолчанию — `song`. В `song`
лирика поётся, под неё генерируется инструментальная подложка, и результат
миксуется; в `narrated` поведение прежнее (речь поверх музыки). Режим SHALL
сохраняться в записи и читаться через опрос состояния.

#### Scenario: Пение по умолчанию

- **WHEN** задача поставлена без явного режима
- **THEN** выполняется пение с подложкой, а в записи режим `song`

#### Scenario: Явный narrated

- **WHEN** в запросе указан режим `narrated`
- **THEN** выполняется прежняя цепочка речь + музыка

#### Scenario: Неизвестный режим

- **WHEN** передан режим вне `song`/`narrated`
- **THEN** запрос отклоняется с кодом `400` до создания задачи

## MODIFIED Requirements

### Requirement: Стадии выполнения

Выполнение SHALL проходить стадии по режиму: в `narrated` — `tts` (синтез
речи), `music`, `mix`; в `song` — `tts` (синтез вокала), `music` (подложка),
`mix` (сведение). Текущая стадия SHALL быть видна через опрос состояния, пока
задача в `running`.

#### Scenario: Ход выполнения

- **WHEN** задача выполняется
- **THEN** состояние показывает текущую стадию по ходу работы

#### Scenario: Завершённая задача

- **WHEN** задача завершилась
- **THEN** её статус `done` или `failed`, стадия больше не меняется
