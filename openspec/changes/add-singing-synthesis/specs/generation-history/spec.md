# Spec Delta

## ADDED Requirements

### Requirement: Режим в записи

Запись о генерации SHALL хранить режим (`song` или `narrated`). Для задач в
режиме `song` параметры озвучки не заполняются, вместо них сохраняются теги
музыки и seed.

#### Scenario: Запись песни

- **WHEN** выполнена задача в режиме `song`
- **THEN** в записи режим `song`, голос пуст, теги и seed сохранены

#### Scenario: Запись озвучки

- **WHEN** выполнена задача в режиме `narrated`
- **THEN** в записи режим `narrated` и параметры озвучки
