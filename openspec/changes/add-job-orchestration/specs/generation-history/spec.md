# Spec Delta

## ADDED Requirements

### Requirement: Файлы результата

Запись о генерации SHALL быть связана с файлами всех созданных форматов: формат и
путь хранятся отдельными строками, связанными с записью. При отсутствии файлов
(задача не завершилась или упала) связей нет.

#### Scenario: Два формата

- **WHEN** генерация завершилась с MP3 и M4A
- **THEN** у записи есть две связанные строки файлов с форматами `mp3` и `m4a` и путями

#### Scenario: Задача с ошибкой

- **WHEN** генерация завершилась со статусом `failed`
- **THEN** связанных файлов у записи нет
