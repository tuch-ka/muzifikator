# Proposal

## Why

Речь уже синтезируется, но накладывать её не на что: музыкальной подложки нет.
Она должна генерироваться локально (никаких внешних сервисов), каждый раз новая,
длиной под речь — поэтому нужны управляемый seed, сборка из сегментов окна модели
и текстовый промпт стиля.

## What Changes

- Появляется генерация инструментальной музыки локально через MusicGen
  (`transformers`): промпт стиля, требуемая длительность, seed.
- Модель выбирается конфигурацией (`MUSICGEN_MODEL`, по умолчанию
  `facebook/musicgen-small`); веса кладутся в `models/` вне репозитория и
  скачиваются с Hugging Face при первом запуске (`CONSTITUTION.md` п. 2.4).
- Seed: заданный используется как есть, случайный генерируется и возвращается в
  результате; тот же seed, промпт и модель на том же окружении дают тот же трек.
- Длительность больше окна модели (30 с) собирается из сегментов с кроссфейдом
  2 с; музыка получается не короче запрошенной.
- Промпт стиля по умолчанию — `folk metal`, меняется конфигурацией.
- Кэша сгенерированной музыки нет: каждый вызов генерирует заново.
- Результат — WAV-файл в рабочем каталоге, переданном вызывающей стороной
  (без записи в репозиторий).

Явно вне скоупа: микс, дакинг, фейды и экспорт (фаза 5), очередь задач и запись
в историю (фаза 6), HTTP API и UI (фазы 7–8). Мелодическое и аудио-кондиционирование,
fine-tuning, CUDA-сборка `torch`, выбор модели из UI.

## Capabilities

### New Capabilities

- `music-generation`: локальная генерация музыкальной подложки по промпту,
  длительности и seed, со сборкой длинных треков из сегментов.

### Modified Capabilities

Нет: существующие capability не меняют поведения. Общий ffmpeg-слой
(`MediaTools`) выделяется из `speech/audio.py` как внутренний рефакторинг — на
поведение речи это не влияет.

## Impact

- Код: новый подпакет `src/muzifikator/music/` (провайдер MusicGen, сервис,
  сборка сегментов); общий `src/muzifikator/media.py` (ffmpeg/ffprobe, кроссфейд);
  `config.py` — модель, каталог весов, промпт по умолчанию, устройство.
- Зависимости: `torch`, `transformers`; numpy приходит с ними.
- Данные: `models/` (уже в `.gitignore`), временные WAV там, куда укажет вызывающий.
- Документация: `docs/capabilities/music-generation.md`,
  `docs/architecture.md` (компонент музыки), `docs/operations.md` (скачивание
  модели, время генерации, память), `docs/licenses.md` (ссылка на раздел MusicGen).
- Трекер: GitHub issue `tuch-ka/muzifikator#4`.
- Сеть: только Hugging Face за весами; внешних записей нет.
