# Spec Delta

## Purpose

Даёт UI то, что нужно до первой генерации и после неё: список готовых файлов в
выходном каталоге и сохранённые пользовательские настройки, которые применяются
к новым задачам.

## ADDED Requirements

### Requirement: Листинг файлов

Система SHALL отдавать содержимое каталога внутри выходного каталога:
относительный путь, абсолютный корень и записи с именем, относительным путём,
типом (файл или каталог), размером и временем изменения. Записи SHALL
сортироваться: сначала каталоги, затем по имени без учёта регистра.

#### Scenario: Корень по умолчанию

- **WHEN** запрошен листинг без пути
- **THEN** возвращается содержимое выходного каталога и его абсолютный путь

#### Scenario: Вложенный каталог

- **WHEN** запрошен листинг подкаталога
- **THEN** возвращается его содержимое, а пути записей — относительно корня

#### Scenario: Пустой каталог

- **WHEN** каталог существует и пуст
- **THEN** ответ содержит пустой список, а не ошибку

### Requirement: Защита путей

Система MUST NOT выходить за пределы выходного каталога: пути с `..`,
абсолютные пути и симлинки, ведущие наружу, SHALL отклоняться с кодом `400`.

#### Scenario: Выход через ..

- **WHEN** путь содержит `..` и выводит за корень
- **THEN** ответ `400`, содержимое не отдаётся

#### Scenario: Абсолютный путь

- **WHEN** путь начинается с `/`
- **THEN** ответ `400`

#### Scenario: Симлинк наружу

- **WHEN** симлинк внутри корня указывает за его пределы
- **THEN** ответ `400`

#### Scenario: Каталога нет

- **WHEN** путь внутри корня не существует
- **THEN** ответ `404`

#### Scenario: Путь указывает на файл

- **WHEN** запрошен листинг пути, который является файлом
- **THEN** ответ `400`

### Requirement: Чтение настроек

Система SHALL отдавать действующие значения настроек по белому списку: голос,
теги музыки, темп, тон, рык и форматы вывода. Если значение не сохранено,
возвращается действующее по умолчанию или `null`, если умолчания нет.

#### Scenario: Настройки не менялись

- **WHEN** запрошены настройки на чистой базе
- **THEN** возвращаются значения из конфигурации и умолчания, а голос — `null`

#### Scenario: Часть значений сохранена

- **WHEN** сохранён только голос
- **THEN** остальные значения приходят из конфигурации и умолчаний

### Requirement: Запись настроек

Система SHALL принимать частичное обновление настроек: указанные ключи
сохраняются, остальные не меняются. Неизвестный ключ или некорректное значение
SHALL отклоняться с кодом `400`; при отказе ничего не сохраняется.

#### Scenario: Частичное обновление

- **WHEN** переданы только `music_tags` и `growl`
- **THEN** меняются только они, остальные настройки остаются прежними

#### Scenario: Неизвестный ключ

- **WHEN** передан ключ вне белого списка
- **THEN** ответ `400` с именем ключа, настройки не меняются

#### Scenario: Некорректный формат вывода

- **WHEN** передан формат, которого система не умеет
- **THEN** ответ `400`, настройки не меняются

#### Scenario: Перезапуск

- **WHEN** настройки сохранены и процесс перезапущен
- **THEN** чтение возвращает сохранённые значения

### Requirement: Настройки как умолчания задачи

При постановке генерации отсутствующие параметры SHALL браться из сохранённых
настроек: теги музыки, темп, тон, рык и форматы. Голос MAY отсутствовать в
запросе, если он сохранён в настройках; иначе запрос отклоняется.

#### Scenario: Пустые параметры

- **WHEN** запрос содержит только текст, а настройки задают голос и теги
- **THEN** задача выполняется с этими настройками

#### Scenario: Нет ни голоса, ни настроек

- **WHEN** запрос без голоса, а в настройках голос не сохранён
- **THEN** ответ `422`, задача не создаётся

#### Scenario: Явный параметр главнее

- **WHEN** запрос содержит теги, отличные от настроек
- **THEN** используется значение из запроса, настройки не меняются
