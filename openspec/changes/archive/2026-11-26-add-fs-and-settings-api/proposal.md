# Proposal

## Why

Сервис умеет генерировать, но UI (фаза 9) нечего показать и нечего сохранить:
нет списка готовых файлов, нет способа прочитать и изменить пользовательские
настройки — сейчас они задаются только переменными окружения, которые UI не
трогает. Кроме того, без явных корней и проверки путей листинг файлов — дыра.

## What Changes

- Появляется листинг файлов внутри выходного каталога: имя, размер, время
  изменения, тип, сортировка «каталоги, затем по имени».
- Появляется защита путей: выход за `OUTPUT_DIR`, абсолютные пути и симлинки
  наружу отклоняются.
- Появляются настройки через API: чтение действующих значений и частичное
  обновление по белому списку ключей (голос, теги музыки, темп, тон, рык,
  форматы); значения сохраняются в таблицу `settings` и переживают перезапуск.
- Задача генерации начинает использовать настройки как значения по умолчанию:
  отсутствующие в запросе параметры берутся из сохранённых, голос можно не
  указывать, если он сохранён.
- Эндпоинты задач, файлов и настроек собираются в отдельные роутеры, чтобы
  фаза 9 добавила UI без переписывания `app.py`.

Явно вне скоупа: HTML/JS-интерфейс (фаза 9), скачивание и стриминг медиа,
загрузка файлов, редактирование истории, авторизация, несколько корней.

## Capabilities

### New Capabilities

- `web-interface`: HTTP-поверхность для UI — листинг файлов внутри выходного
  каталога с защитой путей и чтение/запись пользовательских настроек.

### Modified Capabilities

Нет: `persisted-settings` описывает хранение и уже умеет JSON-значения; API
только использует его. `generation-jobs` не меняет требований — голос и
параметры остаются теми же, добавляется источник значений по умолчанию.

## Impact

- Код: новый пакет `src/muzifikator/api/` (роутеры задач, файлов, настроек,
  хранилище настроек); `app.py` — сборка роутеров, без собственных эндпоинтов;
  `jobs/pipeline.py` получает разрешённые параметры из запроса как раньше.
- Данные: новые ключи в `settings`, схема не меняется.
- Документация: `docs/capabilities/web-interface.md`, `docs/operations.md`
  (API файлов и настроек), `docs/architecture.md` (слой API).
- Трекер: GitHub issue `tuch-ka/muzifikator#11`.
- Сеть не используется; внешних записей нет.
