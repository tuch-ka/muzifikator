# Proposal

## Why

Каркас и хранилище готовы, но звука нет: без слоя синтеза речи следующие фазы
(музыка, микс) нечего микшировать. Провайдер нужен за интерфейсом сразу, потому
что второй локальный провайдер появится в фазе 9, а edge-tts — сетевой и
нестабильный (см. `CONSTITUTION.md` п. 5.2), значит его отказы надо уметь
переживать и не платить за них повторным синтезом.

## What Changes

- Появляется единый интерфейс провайдера синтеза речи: синтез по тексту и
  голосу, параметры темпа и тона, список голосов, понятные ошибки.
- Появляется первый провайдер — `edge-tts`; сеть ограничена его endpoint
  (`CONSTITUTION.md` п. 2.4).
- Появляется список голосов: имя, локаль, пол; запрашивается у провайдера один
  раз за процесс.
- Появляется файловый кэш озвучки в `.cache/tts/`: ключ — провайдер, голос,
  параметры и текст; повторный запрос не вызывает провайдера и переживает
  перезапуск.
- Появляется настраиваемый лимит кэша на диске (`TTS_CACHE_LIMIT_MIB`, по
  умолчанию 200 МиБ, `0` — без лимита): при превышении удаляются записи, к
  которым дольше всего не обращались.
- Длительность результата измеряется по готовому файлу через `ffprobe`, а не
  оценивается по тексту.
- Появляется «рык»: обработка синтезированного голоса (понижение тона и
  сатурация) через `ffmpeg` с сохранением длительности; результат кэшируется
  отдельно от необработанной речи.
- Длинный текст разбивается на части, синтезируется по частям и склеивается в
  один файл — ограничение длины запроса edge-tts не должно ломать генерацию.

Явно вне скоупа: музыка, микс и выходные файлы (фазы 4–5), очередь задач и
запись в историю (фаза 6), HTTP API и UI (фазы 7–8), второй провайдер и
переключение в UI (фаза 9). Автоматического fallback между провайдерами нет —
`ROADMAP.md` относит его к отложенным.

## Capabilities

### New Capabilities

- `speech-synthesis`: синтез речи заданным голосом с параметрами, список
  голосов, длительность результата, кэш, обработка «рык».

### Modified Capabilities

Нет: `ffmpeg-preflight`, `service-health`, `generation-history`,
`persisted-settings`, `storage-schema` не меняют поведения.

## Impact

- Код: новый подпакет `src/muzifikator/speech/` (интерфейс, edge-tts,
  кэш с лимитом, ffmpeg-обработка, сервис); `config.py` — каталог кэша и лимит.
- Зависимости: `edge-tts`; `ffmpeg`/`ffprobe` уже обязательны и проверяются
  preflight.
- Данные: `.cache/tts/` (уже в `.gitignore`), файлы озвучки и sidecar-метаданные.
- Документация: `docs/capabilities/speech-synthesis.md`,
  `docs/architecture.md` (слой речи), `docs/operations.md` (кэш, чистка,
  проблемы с сетью), `docs/licenses.md` (статус edge-tts как неофициального
  endpoint).
- Трекер: GitHub issue `tuch-ka/muzifikator#3`.
- Сетевых обращений, кроме endpoint edge-tts, нет; внешних записей нет.
