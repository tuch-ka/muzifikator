# Spec Delta

## MODIFIED Requirements

### Requirement: Выходной каталог

Файлы SHALL сохраняться в действующий каталог хранения: сохранённая настройка
`output_dir`, а при её отсутствии — `OUTPUT_DIR` из окружения (по умолчанию
`~/muzifikator`). Каталог SHALL использоваться в абсолютном виде и создаваться
при необходимости.

#### Scenario: Каталога нет

- **WHEN** действующего каталога не существует
- **THEN** он создаётся, и файлы появляются в нём

#### Scenario: Каталог изменён

- **WHEN** настройка `output_dir` указывает на другой существующий каталог
- **THEN** новые файлы сохраняются в нём, старые остаются на своих местах

## ADDED Requirements

### Requirement: Абсолютные пути

Путь каждого созданного файла SHALL записываться в базу в абсолютном виде.
Переносить записи прежних версий не требуется: приложение не развёрнуто, база
хранилища создаётся заново.

#### Scenario: Новый файл

- **WHEN** задача завершена успешно
- **THEN** в записи о файле хранится абсолютный путь

## REMOVED Requirements

### Requirement: Подкаталог результата

**Reason**: подпапки заменяются одним настраиваемым каталогом хранения.

**Migration**: параметр `folder` удаляется из API и интерфейса; файлы в
подкаталогах остаются на диске, но приложению неизвестны.
