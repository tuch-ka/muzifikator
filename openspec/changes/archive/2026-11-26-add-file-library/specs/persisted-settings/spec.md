# Spec Delta

## ADDED Requirements

### Requirement: Каталог хранения

Настройка `output_dir` SHALL храниться в таблице настроек и SHALL принимать
только абсолютный путь к существующему каталогу, доступному на запись. Значение
SHALL нормализоваться перед сохранением; при отсутствии настройки действует
каталог по умолчанию из окружения.

#### Scenario: Корректный каталог

- **WHEN** сохраняется абсолютный путь к существующему каталогу
- **THEN** значение сохраняется в нормализованном виде и читается обратно

#### Scenario: Относительный путь

- **WHEN** передан относительный путь
- **THEN** ответ `400`, настройка не меняется

#### Scenario: Каталога нет

- **WHEN** передан путь, которого не существует
- **THEN** ответ `400`, каталог не создаётся

#### Scenario: Путь указывает на файл

- **WHEN** передан путь к файлу
- **THEN** ответ `400`

#### Scenario: Нет прав на запись

- **WHEN** каталог существует, но недоступен на запись
- **THEN** ответ `400`

#### Scenario: Перезапуск

- **WHEN** каталог сохранён и процесс перезапущен
- **THEN** действующий каталог хранения остаётся тем же
