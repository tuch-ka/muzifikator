# Proposal

## Why

Все части есть по отдельности: озвучка, музыка, микс. Пользователь не может
получить файл — нет ничего, что связывает их, ведёт ход работы и говорит, чем
дело кончилось. Кроме того, тяжёлая генерация не должна держать HTTP-запрос
открытым на минуты, а состояние обязано переживать перезапуск.

## What Changes

- Появляется API задач: постановка генерации (`POST /api/generations`), опрос
  состояния по идентификатору и список последних задач.
- Появляется single-flight: одна генерация одновременно; запрос во время работы
  получает `409` с идентификатором текущей задачи.
- Появляется оркестрация стадий `tts → music → mix` с записью статуса и стадии в
  `generations` по ходу работы.
- Появляется запись файлов результата: каждый формат со своим путём в новой
  таблице `generation_files` (миграция).
- Появляется список голосов (`GET /api/voices`), без которого нельзя поставить
  задачу из UI.
- Появляется восстановление после рестарта: задачи, оставшиеся в `running`,
  переводятся в `failed` с понятной причиной.

Явно вне скоупа: API файлов и настроек, UI (фазы 8–9), отмена задачи, приоритеты,
очередь ожидания, параллельные генерации, второй провайдер TTS.

## Capabilities

### New Capabilities

- `generation-jobs`: постановка и выполнение генерации — single-flight, стадии,
  опрос состояния, история, ошибки пайплайна, восстановление после рестарта,
  список голосов.

### Modified Capabilities

- `generation-history`: добавляется требование «Файлы результата» — записи о
  генерации связаны с файлами всех созданных форматов.

## Impact

- Код: `src/muzifikator/jobs/` (менеджер задач, запуск пайплайна), эндпоинты в
  `app.py`, фабрика зависимостей в `__main__.py`; `storage/repo.py` — файлы
  результата и сброс «зависших» задач; новая миграция.
- Данные: таблица `generation_files` (миграция Alembic); `generations` не
  меняется по структуре.
- Зависимости: новых нет.
- Документация: `docs/capabilities/generation-jobs.md`, обновление
  `docs/capabilities/generation-history.md`, `docs/operations.md` (API задач),
  `docs/architecture.md` (JobManager, поток стадий).
- Трекер: GitHub issue `tuch-ka/muzifikator#9`.
- Сеть: только edge-tts при выполнении озвучки; внешних записей нет.
