# Spec Delta

## ADDED Requirements

### Requirement: Подкаталог результата

Система SHALL поддерживать запись результата в подкаталог выходного каталога:
путь относительный, вложенность разрешена, несуществующий подкаталог создаётся.
Абсолютный путь и выход за пределы выходного каталога SHALL отклоняться.

#### Scenario: Новый подкаталог

- **WHEN** результат пишется в подкаталог, которого ещё нет
- **THEN** подкаталог создаётся, а файлы появляются в нём

#### Scenario: Вложенность

- **WHEN** указан подкаталог `2026/11/26`
- **THEN** создаются все уровни, имена файлов остаются прежними

#### Scenario: Выход за корень

- **WHEN** подкаталог содержит `..` и выводит за выходной каталог
- **THEN** запись отклоняется с ошибкой, файлы не создаются
