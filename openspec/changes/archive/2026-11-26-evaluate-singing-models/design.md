# Design

## Context

См. `proposal.md` — Why. Реестры дали: мультиязычных русских певческих моделей нет;
на GitHub есть NNSVS-путь с русским банком «Llane Crow AI RU β» (женский, ≈1 ч,
17 песен, D#3–E5) и репозиторием `SCERYP/nnsvs-russian-support` (таблицы фонем,
hed). NNSVS поёт по нотам и лирике — значит при входе «лирика + теги» нужен
генератор мелодии. Машина M4 Pro, 48 ГБ RAM; ограничение владельца — 5 минут и
16 ГБ на песню.

## Goals / Non-Goals

**Goals:**

- Выяснить, есть ли у NNSVS-банка готовое качество «слушабельного русского
  пения», и как его запустить (готовый модель против обучения; ENUNU против
  `nnsvs` CLI).
- Дать факты и сэмплы для решения go/no-go.

**Non-Goals:**

- Дообучение банка, обучение с нуля, сбор датасета.
- Продакшн-интеграция, API, UI.
- Достижение качества Suno: цель — «узнаваемо поёт по-русски».

## Decisions

### 1. Пути и порядок

| Путь | Суть | Роль |
|---|---|---|
| C′ | NNSVS + банк Llane Crow | основной |
| D | edge-tts + WORLD (F0 → мелодия) | запасной, дешёвый |
| E | D + RVC-тембр | опция при ясной лицензии |

Порядок: сначала инвентаризация C′ (готов ли `.nnsvs`-модель или нужно обучать),
параллельно D (он не требует внешних банков). E — после D и только с лицензией.

### 2. NNSVS: что выясняем первым шагом

Голосовой банк — это данные для обучения и UTAU/OpenUtau-банк с плагином ENUNU,
а не обязательно готовая модель. Задачи первого шага:

1. Есть ли в репозитории готовая `.nnsvs`-модель или только датасет.
2. Можно ли синтезировать без GUI: через `nnsvs` (Python) с hed/table из
   `nnsvs-russian-support`, или через OpenUtau + ENUNU headless.
3. Требуется ли обучение на M4 Pro и сколько это времени; если обучение — путь
   помечается «тяжёлый», но фиксируем оценку, а не отказываемся сразу.
4. Фонемайзер: `hhskt_ru_phonemizer` (MIT) или таблицы из `nnsvs-russian-support`.

### 3. Генератор мелодии

Процедурная мелодия: тональность и темп из тегов, длина — из лирики (слоги →
доли). Простая схема: минорная/мажорная гамма, по одной ноте на слог, пары слогов
→ восьмые, акценты на ударные гласные; хвост фразы — тоника. Результат — UST/MIDI
или список «слог → нота/длительность» для NNSVS.

Почему процедурно, а не модель: на старте важнее оценить сам голос; генератор
нужен, чтобы NNSVS получил ноты, и его качество вторично.

### 4. Метрики

- Время и пик памяти (порог 16 ГБ; превышение = отклонение пути).
- Разборчивость: Whisper WER по лирике (ориентир; ASR на пении ошибается).
- Субъективно 1–5 «это пение»: сэмплы 5–10 с слушает владелец.

Порог: go (Suno-подобное) — WER ≤ 20% и ≥3/5; go (робот-пение) — WER ≤ 20% и
≥2/5; иначе no-go.

### 5. Лицензии — не гейт

Использование личное, без распространения и монетизации, поэтому лицензии не
блокируют ни один путь. В отчёте лицензия каждого компонента фиксируется
справочно; если какая-то не разрешает даже личное использование, репозиторий
делается приватным (решение владельца). Коммерческие модели всё равно не
загружаются: не по лицензии, а по конституции (некоммерческое использование).

### 6. Поиск в ModelScope и Civitai

Только чтение, без авторизации и интеграции: ищем русские голосовые банки
(NNSVS/DiffSinger) и RVC-модели. Найденное — в отчёт с лицензией и ссылкой.
Загрузка — только кандидатов с ясной лицензией.

### 7. Решение и эскиз интеграции

Отчёт завершается рекомендацией go/no-go. Если go — будущий `add-singing-synthesis`
строится как провайдер `sing(lyrics, tags, duration, seed) → микс`, у задачи
появляется режим `song`; narrated остаётся либо заменяется. Эскиз фиксируется, но
не реализуется здесь.

## Risks / Trade-offs

- Банк может оказаться только датасетом → обучение NNSVS на M4 Pro не проверено;
  фиксируем время, не запускаемся в долгий эксперимент без согласия владельца.
- Бета-банк на 1 ч данных может звучать грубо → D остаётся запасным.
- Whisper на пении может ошибаться → WER как ориентир, решение по прослушиванию.
- Временные зависимости конфликтуют с основным venv → отдельное `.venv-singing`.
- Лицензии фиксируются справочно, но не блокируют работу (личное
  использование).

## Migration Plan

Код приложения не меняется. Откат — удалить `tools/eval/`, отчёт и веса.

## Open Questions

Нет: состав, генератор мелодии, источники и отношение к лицензиям зафиксированы
владельцем.
