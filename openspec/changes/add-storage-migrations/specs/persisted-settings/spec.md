# Spec Delta

## Purpose

Сохраняет пользовательские настройки в базе, чтобы выбранные голос, теги и
параметры не приходилось вводить заново после перезапуска.

## ADDED Requirements

### Requirement: Сохранение настройки

Система SHALL сохранять настройку по строковому ключу, заменяя прежнее значение
целиком, и обновлять время изменения.

#### Scenario: Новая настройка

- **WHEN** сохраняется значение по ключу, которого не было
- **THEN** ключ появляется в хранилище с переданным значением и текущим временем изменения

#### Scenario: Замена значения

- **WHEN** сохраняется новое значение по существующему ключу
- **THEN** читается только последнее значение, а время изменения обновляется

### Requirement: Чтение настройки

Система SHALL читать значение по ключу, возвращая отсутствие значения для
неизвестного ключа, и SHALL позволять подставить значение по умолчанию, если
ключ не сохранён.

#### Scenario: Сохранённый ключ

- **WHEN** читается ранее сохранённый ключ
- **THEN** возвращается последнее сохранённое значение

#### Scenario: Неизвестный ключ

- **WHEN** читается ключ, которого нет в хранилище
- **THEN** возвращается значение по умолчанию, если оно передано, иначе признак отсутствия; ошибка не возникает

### Requirement: Составные значения

Настройка SHALL хранить значение произвольной JSON-совместимой формы — строку,
число, логическое значение, список или объект — и возвращать его без искажений.

#### Scenario: Объект и список

- **WHEN** сохраняется объект с вложенными полями, затем читается
- **THEN** возвращается та же структура; для списка и числа — аналогично

### Requirement: Сохранность между перезапусками

Настройки SHALL сохраняться в файле базы и быть доступны после перезапуска
процесса.

#### Scenario: Перезапуск процесса

- **WHEN** процесс остановлен и запущен снова
- **THEN** сохранённые настройки читаются с прежними значениями

### Requirement: Независимость от истории

Настройки MUST NOT теряться при удалении или добавлении записей истории
генераций.

#### Scenario: История изменена

- **WHEN** в историю добавлена новая запись
- **THEN** сохранённые настройки остаются прежними
