# Spec Delta

## Purpose

Кладёт готовое аудио в понятное место с понятным именем в нужных форматах и не
оставляет мусора при сбоях.

## ADDED Requirements

### Requirement: Форматы экспорта

Система SHALL сохранять итог в MP3 и M4A (AAC) по умолчанию и SHALL позволять
ограничить набор форматов запросом.

#### Scenario: Оба формата

- **WHEN** микс завершён без указания форматов
- **THEN** создаются два файла — MP3 и M4A — с одинаковой длительностью

#### Scenario: Один формат

- **WHEN** в запросе указан только MP3
- **THEN** создаётся только MP3-файл

#### Scenario: Неизвестный формат

- **WHEN** запрошен формат, который система не умеет
- **THEN** запрос отклоняется с ошибкой до запуска микса

### Requirement: Имя файла

Имя SHALL состоять из времени создания `YYYYMMDD-HHMMSS` и slug из начала текста.
Slug SHALL состоять только из латинских букв, цифр и дефисов: кириллица
транслитерируется, остальные символы заменяются дефисом. Длина — до 40 знаков;
пустой slug заменяется на `audio`.

#### Scenario: Обычный текст

- **WHEN** текст начинается словами «Привет, мир!»
- **THEN** имя содержит `20261126-072500-privet-mir` и расширение формата

#### Scenario: Текст без пригодных символов

- **WHEN** из текста не получается slug
- **THEN** используется запасной slug `audio`, и имя остаётся корректным

### Requirement: Выходной каталог

Файлы SHALL сохраняться в каталог из настройки `OUTPUT_DIR` (по умолчанию `out/`),
каталог SHALL создаваться при необходимости и MUST NOT находиться под контролем
версий.

#### Scenario: Каталога нет

- **WHEN** выходного каталога не существует
- **THEN** он создаётся, и файлы появляются в нём

### Requirement: Атомарная запись

Система MUST NOT оставлять частичных файлов: результат SHALL записываться во
временные файлы и переименовываться только после успешного кодирования всех
запрошенных форматов.

#### Scenario: Сбой кодирования второго формата

- **WHEN** MP3 записан, а M4A не удался
- **THEN** ни одного файла с итоговым именем не остаётся

### Requirement: Защита от перезаписи

Существующие файлы MUST NOT перезаписываться: при совпадении имени SHALL
добавляться числовой суффикс.

#### Scenario: Имя занято

- **WHEN** файл с рассчитанным именем уже существует
- **THEN** создаётся файл с суффиксом `-2`, `-3` и так далее, прежний не меняется

### Requirement: Отчёт о результате

Система SHALL возвращать пути ко всем созданным файлам и их формат.

#### Scenario: Итог экспорта

- **WHEN** экспорт завершён
- **THEN** результат перечисляет пути и форматы всех созданных файлов
