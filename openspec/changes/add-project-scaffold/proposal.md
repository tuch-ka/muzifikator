# Proposal

## Why

Репозиторий содержит только документы: спецификаций и кода нет, запускать нечего.
Без каркаса (проект, конфиг, логирование, проверка внешних бинарей, health-эндпоинт)
каждая следующая фаза начинала бы с собственных заготовок, а ffmpeg-зависимость
проявлялась бы в момент первой генерации — то есть после долгой загрузки модели.

## What Changes

- Появляется runnable uv-проект: `pyproject.toml`, `src/`-layout, пакет
  `muzifikator`, точка входа `python -m muzifikator` / консольная команда.
- Появляется конфигурация приложения: значения по умолчанию, переопределение через
  переменные окружения и локальный `.env`, включая `FFMPEG_BIN` и `FFPROBE_BIN`.
- Появляется логирование: уровень из конфигурации, вывод в stderr, единый формат.
- Появляется preflight внешних бинарей: при старте приложение находит `ffmpeg` и
  `ffprobe`, проверяет их запуск и версию; при отсутствии — завершается с понятным
  сообщением о установке, а не стартует в неработоспособном виде.
- Появляется HTTP-сервис (FastAPI) с `GET /api/health`, отдающим состояние сервиса
  и результат preflight.
- Появляется `docs/operations.md`: запуск, окружение, установка ffmpeg.

Явно вне скоупа: хранилище и миграции, TTS, музыка, микс, задачи, UI, тесты
уровня фаз 10. Docker не появляется.

## Capabilities

### New Capabilities

- `ffmpeg-preflight`: обнаружение, проверка и версия внешних бинарей `ffmpeg` и
  `ffprobe`; предсказуемый отказ при их отсутствии до начала любой работы.
- `service-health`: HTTP-эндпоинт состояния сервиса, отдающий версию приложения и
  результат preflight для внешнего наблюдателя.

### Modified Capabilities

Нет: `openspec/specs/` пуст, это первый change.

## Impact

- Код: новый пакет `src/muzifikator/` (конфиг, логирование, preflight, приложение).
- Зависимости: `fastapi`, `uvicorn`, `pydantic-settings`; dev — `pytest`, `ruff`
  (набор уточняется в design).
- Внешние бинари: `ffmpeg`, `ffprobe` в `PATH` или в `FFMPEG_BIN`/`FFPROBE_BIN`.
- Документация: новый `docs/operations.md`, обновление `docs/architecture.md`
  (появляется процесс запуска и health-эндпоинт).
- Данные: каталоги `logs/`, `data/`, `.cache/` уже в `.gitignore`, код их не создаёт.
- Трекер: GitHub issue `tuch-ka/muzifikator#1`
  (https://github.com/tuch-ka/muzifikator/issues/1).
- Сетевых и внешних записей нет.
