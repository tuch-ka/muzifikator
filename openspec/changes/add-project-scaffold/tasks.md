# Tasks

## 1. Проект и зависимости

- [ ] 1.1 Поставить `uv` и убедиться, что `uv --version` печатает версию (macOS: `brew install uv`)
- [ ] 1.2 Создать `pyproject.toml` (`requires-python = ">=3.12,<3.13"`, зависимости `fastapi`, `uvicorn`, `pydantic-settings`, dev-группа `pytest`, `httpx`, `ruff`, `[project.scripts] muzifikator = "muzifikator.__main__:main"`), каталог `src/muzifikator/` с `__init__.py`; проверить `uv sync` без ошибок и `uv run python -c "import muzifikator"` с кодом 0
- [ ] 1.3 Добавить в `.gitignore` `.env`; проверить, что `git status` не показывает `.env` после его создания с тестовой строкой

## 2. Конфигурация и логирование

- [ ] 2.1 Реализовать `config.py` на `pydantic-settings` с полями `host` (`127.0.0.1`), `port` (`8000`), `log_level` (`INFO`), `ffmpeg_bin`, `ffprobe_bin` и поддержкой `.env`; проверить, что `HOST=0.0.0.0`, `PORT=9000`, `FFMPEG_BIN=/tmp/x` меняют значения в `Settings()`
- [ ] 2.2 Реализовать `logging_setup.py`: один обработчик в stderr, формат с временем, уровнем и логгером, уровень из настроек; проверить запуском с `LOG_LEVEL=DEBUG`, что DEBUG-строка видна, а с `LOG_LEVEL=ERROR` — нет
- [ ] 2.3 Реализовать `__main__.py` с настройкой логирования и чтением настроек до любой другой работы; проверить `uv run muzifikator --help` (или эквивалентный ранний выход), что логирование и настройки не падают

## 3. Preflight

- [ ] 3.1 Реализовать в `preflight.py` разрешение пути (настройка → `shutil.which`) и проверку `-version` с таймаутом 5 с, извлечением версии и снимком (`available`, `path`, `version`, `error`, общий `ok`); проверить `pytest`-тестами на подставных бинарях: успех, ненулевой код, таймаут, отсутствие файла
- [ ] 3.2 Реализовать текст отказа: перечисление всех проблемных бинарей, команды установки для macOS, Debian/Ubuntu и Fedora, напоминание про `FFMPEG_BIN`/`FFPROBE_BIN`; проверить тестом, что сообщение для случая «нет обоих бинарей» содержит обе строки установки и оба имени переменных
- [ ] 3.3 Подключить preflight в `__main__.py` до запуска сервера и завершать процесс с кодом 1 при `ok = false`; проверить запуском с пустым `PATH`, что порт не слушается, код выхода 1, сообщение в stderr

## 4. Приложение и health

- [ ] 4.1 Реализовать `app.py`: фабрику приложения, приём снимка preflight, `GET /api/health` с полями `status`, `app_version`, `binaries` (оба бинаря всегда присутствуют, неизвестная версия сериализуется как `null`); проверить `httpx`-тестом, что ответ `200` и содержит требуемые поля
- [ ] 4.2 Проверить отсутствие побочных эффектов: тест, что обработчик health не вызывает `subprocess`/`shutil.which` повторно (подмена функций-шпионов или отсутствие роста вызовов), и тест, что `POST /api/health` даёт `405`
- [ ] 4.3 Собрать полный запуск: `uv sync`, `uv run muzifikator`, `curl -s http://127.0.0.1:8000/api/health`; убедиться, что версия приложения и пути бинарей заполнены, в ответе нет переменных окружения
