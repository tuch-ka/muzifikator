# Proposal

## Why

API готов, но пользоваться им можно только через `curl`. Нужен минимальный
интерфейс: ввести текст, выбрать голос и теги, нажать «сгенерировать», увидеть
ход по стадиям и получить файл. Заодно нужна папка: результаты удобно
раскладывать по подкаталогам, а не держать всё в одном `out/`.

## What Changes

- Появляется одностраничный интерфейс на статике (`src/muzifikator/web/`):
  HTML, CSS и JS без сборки и без внешних CDN; отдаётся самим FastAPI.
- Форма: текст, голос из списка провайдера, теги музыки с предзаполнением из
  настроек, выбор папки результата.
- Прогресс: интерфейс опрашивает состояние задачи и показывает стадию
  `tts → music → mix`; форма заблокирована, пока задача выполняется, `409`
  показывается понятным сообщением.
- Результат: список файлов задачи и листинг выбранной папки обновляются после
  завершения; «перегенерировать» повторяет параметры с новым seed.
- Настройки: чтение и сохранение из интерфейса (`GET`/`PATCH /api/settings`);
  сохранённые значения подставляются в форму.
- Постановка генерации получает `folder` — относительный подкаталог внутри
  `OUTPUT_DIR`; сборка пишет туда, каталог создаётся, выход за корень
  отклоняется.

Явно вне скоупа: проигрывание аудио в браузере и стриминг, авторизация,
мобильная вёрстка сверх простой адаптивности, второй провайдер TTS, история
задач в UI сверх текущей задачи и списка файлов.

## Capabilities

### Modified Capabilities

- `web-interface`: добавляются требования «Статический интерфейс», «Форма
  генерации», «Прогресс задачи в интерфейсе», «Результат в интерфейсе»,
  «Перегенерация», «Настройки в интерфейсе» и «Папка результата в запросе».
- `output-files`: добавляется требование «Подкаталог результата» — файлы можно
  писать в подкаталог `OUTPUT_DIR`, несуществующий создаётся, выход за корень
  запрещён.

## Impact

- Код: новый пакет `src/muzifikator/web/` (index.html, app.js, style.css);
  `api/ui.py` — отдача статики; `assembly/base.py` и `assembly/service.py` —
  подкаталог результата; `api/generations.py` — параметр `folder`; общий
  помощник проверки путей `paths.py`.
- Данные: подкаталоги в `OUTPUT_DIR`; схема БД не меняется.
- Упаковка: статика должна попадать в wheel — проверяется сборкой.
- Документация: `docs/capabilities/web-interface.md` и `output-files.md`
  (обновление), `docs/operations.md` (как открыть UI), `docs/architecture.md`.
- Трекер: GitHub issue `tuch-ka/muzifikator#13`.
- Сеть не используется; внешних записей нет.
